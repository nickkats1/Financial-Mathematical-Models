# Financial Mathematical Models

This repository contains code and resources for selected topics in financial mathematics, including:

- Modern Portfolio Theory (MPT)
- Single-Index Models
- Utility Theory
- Value at Risk (VaR) and Expected Shortfall (ES)

## Motivation

I redesigned this repository to explore whether it’s possible to use utility functions to determine an investor’s risk aversion based on their portfolio choices and returns. While there are currently no agent-based models included, I am interested in seeing if others can use or extend this work to develop agents that assess utility and risk preferences. For example, I imagine an agent that uses a questionnaire in its prompt to evaluate an individual’s risk behavior, or an agent workflow designed to maximize utility.

## Getting Started

Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

## Usage

Each topic is organized in a Jupyter Notebook, located in the notebooks folder. Open and run the notebooks to see the code and explanations for each topic.

## Project Structure

- notebooks — Jupyter Notebooks for each topic
- portfolio — Core Python modules for data, models, and utilities
- tests — Unit tests for the modules
